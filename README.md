# E-Yearbook: Buku Tahunan Digital SMKN 1 Lumajang

![Status Proyek](https://img.shields.io/badge/Impact-Budget_Optimization-darkgreen)

**E-Yearbook** adalah platform arsip kenangan digital yang dikembangkan khusus untuk **SMK Negeri 1 Lumajang**. Proyek ini diinisiasi atas permintaan sekolah untuk melakukan transformasi digital terhadap buku tahunan konvensional, dengan tujuan utama memangkas biaya cetak dan mempermudah distribusi.

## 🎯 Dampak & Solusi (Project Impact)
* **Efisiensi Anggaran:** Mengurangi biaya produksi buku tahunan fisik secara signifikan melalui digitalisasi.
* **Aksesibilitas Jangka Panjang:** Memungkinkan ribuan siswa dan alumni mengakses data kenangan kapan saja melalui perangkat mobile/web.
* **Ramah Lingkungan:** Mendukung inisiatif *paperless* sekolah dengan mengurangi penggunaan kertas.

## 🚀 Fitur Utama
* **Pencarian Siswa Cerdas:** Filter data siswa berdasarkan Jurusan (RPL, TKJ, dll), Kelas, dan Tahun Kelulusan.
* **Galeri Kegiatan:** Arsip foto resolusi tinggi untuk kegiatan sekolah dan ekstrakurikuler.
* **Profil Tenaga Pendidik:** Direktori lengkap guru dan staf tata usaha.
* **Admin Dashboard:** Panel CMS bagi tim Jurnalistik/OSIS untuk mengelola upload foto dan data siswa.

## 🛠️ Arsitektur Teknis
* **Framework:** Laravel 
* **Database:** MySQL
* **Frontend:** Bootstrap 
* **Optimasi:** Kompresi aset gambar otomatis untuk performa cepat di jaringan seluler.
